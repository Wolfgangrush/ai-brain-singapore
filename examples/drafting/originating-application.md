## When to use an Originating Application (OA)

Use an OA where:
- it is **required by any written law**; OR
- there is **NOT likely to be a substantial dispute of fact** (Order 6, Rule 2, ROC 2021).

The OA replaced the "Originating Summons" from 1 April 2022. Typical use cases: contract / document interpretation; statutory construction; certain company-law / probate / mental-capacity applications. Evidence is by **affidavit** (not Statement of Claim).

## Procedural anchors

- **Affidavit in support:** filed together with the OA (or as directed).
- **Affidavit in answer by defendant:** within 21 days (in Singapore) / 28 days (outside Singapore) of service.
- **Conversion risk:** the court may order an OA to be converted into an OC where a substantial factual dispute emerges (and may award costs).
- **Form-number anchor:** Verify the prescribed Form number for OA in the current ROC 2021 Subsidiary Legislation Annex / Practice Direction for the operative court (Supreme Court / State Courts) before filing. Research-note pointer: `_research/37-court-form-originating-application.md`.

## Discipline checklist before issuing

- [ ] **Mode of commencement justified**: confirm there is no substantial factual dispute (otherwise an OC is required — see [`originating-claim.md`](./originating-claim.md)).
- [ ] **Statutory anchor**: where commencement is required by statute, cite the operative provision in the "In the Matter of" heading.
- [ ] **Supporting affidavit**: comprehensive, exhibits paginated, sworn / affirmed correctly (see [`affidavit.md`](./affidavit.md)).
- [ ] **Orders sought**: drafted in precise, court-implementable language.
- [ ] **Service**: addresses verified; service-outside-Singapore leave obtained if required (Order 7 ROC 2021).
- [ ] **Counsel sign-off** before filing.

## Verbatim anchor (ROC 2021)
> "An action must be commenced by an originating application if — (a) it is required by any written law; or (b) there is not likely to be a substantial dispute of fact."
> — Order 6, Rule 2, ROC 2021.
